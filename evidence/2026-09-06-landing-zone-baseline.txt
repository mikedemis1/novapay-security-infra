# Landing-zone baseline, captured 2026-09-06, before the hardening pass.
#
# Why this file exists: the decision log recorded on 2026-08-08 that the
# organisation trail had been moved from SSE-S3 to the customer-managed key.
# This capture is the check that was never run at the time. It shows the
# opposite, and it is kept as the "before" half of that fix.
#
# What to look for:
#   1. get-trail has no KmsKeyId field           -> the trail encrypts with SSE-S3
#   2. head-object on a live log object          -> "ServerSideEncryption": "AES256"
#   3. get-bucket-encryption says aws:kms        -> only the bucket default changed,
#                                                   and CloudTrail overrides it per object
#   4. both delegated administrators             -> the management account, not Security
#   5. get-enabled-standards                     -> empty, so Security Hub only relays GuardDuty
#
# Every command is read-only. Account and organisation identifiers are replaced.
